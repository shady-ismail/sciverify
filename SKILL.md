# SciVerify: Agentic Research Software Verification Skill (`WG4-4A / 4B / 4H`)

When generating, refactoring, or reviewing scientific or numerical research software, a passing `pytest` suite written in the same session is **not** sufficient evidence of scientific correctness. Code and tests generated by the same model routinely share identical mathematical blind spots, floating-point assumptions, broadcast shape coincidences, and missing-data bugs.

Follow these five rules before marking any scientific function complete:

## 1. Write the Scientific Contract Before Looking at Implementation Output (`WG4-4B`)
Declare an explicit `ScientificContract` specifying:
- **Domain & Conditioning Bounds**: Offsets up to `|x| >= 1e8`, near-zero magnitudes `|x| <= 1e-8`, rectangular shapes `N != D` (`N >= 2, D >= 3`), and missing values (`NaN`).
- **Metamorphic Relations (`WG4-4H`)**:
  - *Location-shift invariance* (e.g., variance/covariance invariant under `x -> x + delta` for `delta = 2**29`).
  - *Scale homogeneity* (`f(alpha * x) == alpha**k * f(x)` for non-unit `alpha = 2.5` to expose missing factors or mixed unit powers).
  - *Permutation symmetry* (`f(P @ x) == f(x)` or equivariance `f(P @ x) == P @ f(x)`).
- **Conservation Laws**: Total mass, energy, or probability (`sum(p) == 1.0`, `sum(u_t) == sum(u_0)`) verified over `>= 25` integration steps with tight tolerance (`rtol <= 1e-10` for exact invariants), never a single step at `atol = 1e-2`.

## 2. Never Write Tautological or Snapshot Oracles
Forbidden test patterns flagged automatically by `sciverify.ast_tautology`:
- **Mirrored Formula (`TAUT-MIRROR`)**: Copying the implementation expression into `expected = ...` inside the test file.
- **Self-Snapshot (`TAUT-SELF`)**: Running the candidate function once and pasting its float output into `pytest.approx(...)`.
- **Smoke-Only Assertions (`TAUT-SMOKE`)**: Asserting only `.shape`, `isinstance(..., float)`, or `score > 0.5` without checking analytical or metamorphic identities.
- **Toy-Domain Lock (`TAUT-TOY-DOMAIN`)**: Testing only small clean integers `[1.0, 2.0, 3.0]`, square `(3, 3)` matrices, or `NaN`-free inputs.

## 3. Enforce Causal Isolation & Parallel PRNG Independence
- **Cross-Validation / Time-Series**: Prove zero information flow from validation indices `t_val` or future steps `t + 1` into training statistics (`sciverify` checks exact zero sensitivity when `X[val_idx]` is perturbed by `+1e6`).
- **Parallel Monte Carlo**: Never call `np.random.seed(const)` inside workers or pass cloned RNG states. Spawn independent streams via `np.random.SeedSequence(seed).spawn(n_workers)` and assert cross-worker off-diagonal correlation `|r| < 0.15`.

## 4. Run the Deterministic Adversarial Gate
Execute:
```bash
python3 -m sciverify audit path/to/module.py path/to/test_module.py --domain auto
```
If `sciverify` returns a Z3 symbolic counterexample witness or surviving scientific mutant:
1. Inspect the minimal witness vector printed by `sciverify`.
2. Fix the underlying numerical, statistical, or physical implementation defect (never silence it by widening `rtol`/`atol`).
3. Add the synthesized witness as a permanent regression test with an analytical or high-precision (`decimal` / `mpmath` / Welford / `logsumexp`) oracle.
